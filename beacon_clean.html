Setup Guide
Follow these steps in order to configure the full system in Help Scout.
Step 1 — Create custom fields
!
Path: Help Scout — Manage — Mailboxes — select mailbox — Custom Fields — Add a Custom Field
Step 2 — Configure the Beacon form
!
Path: Help Scout — Manage — Beacons — select beacon — Contact — Form Fields
Step 3 — Seed all 22 tags
1
Apply each tag to a test ticket

Tags only exist in Help Scout once they have been applied to a conversation. Open any test ticket and apply all 22 tags from the approved list. This makes them available in Workflows and Reports.

2
Verify in Tags Report

Go to Help Scout — Reports — Tags. All 22 should be visible. This is your baseline for the monthly audit.

Step 4 — Build workflows
!
Path: Help Scout — Manage — Workflows — New Automatic Workflow
